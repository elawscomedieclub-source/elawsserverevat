# EVAT — serveur (Render)

Fichiers : `server.js`, `package.json`, `admin.html`, `.env.example`.
- Démarrage : `npm install` puis `npm start` (Node 18 ou plus).
- Variables : voir `.env.example` (à renseigner dans Render → Environment).
- Contrôle après chaque mise en ligne : `https://VOTRE-SERVEUR/diagnostic?token=VOTRE_ADMIN_TOKEN`
- Administration : `https://VOTRE-SERVEUR/admin`
