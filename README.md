# EVAT Server - Signalisation WebRTC
Ce dossier contient les fichiers nécessaires pour le déploiement de votre serveur backend sur Render ou GitHub :
- `server.js` : Le serveur de signalisation Socket.io avec normalisation des numéros et gestion P2P.
- `package.json` : Les dépendances requises (express, socket.io, cors).
